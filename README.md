# -legal-ai-projects
Proyectos de inteligencia artificial aplicados al Derecho y LegalTech.
## Objetivo
Explorar cómo la inteligencia artificial puede utilizarse para mejorar la investigación jurídica, el análisis de jurisprudencia y la gestión de documentos jurídicos.
## Proyectos
- Analizador de sentencias
- Buscador inteligente de jurisprudencia
- Analizador de contratos
## Tecnologías
- Python
- Inteligencia artificial
- APIs
- GitHub
